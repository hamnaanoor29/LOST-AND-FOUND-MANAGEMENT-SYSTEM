# Lost and Found Management System

A Java-based desktop application designed to streamline the process of reporting, tracking, and recovering lost and found items.



## Features

* User Authentication: Secure Sign-up, Login, and Password Recovery pages.
* Report Lost Items: Easily log details of misplaced items.
* Report Found Items: Register items found around the premises.
* Smart Matching: Compare and check reported items to match lost items with found ones.
* Feedback System: Integrated feedback page for user queries and suggestions.



## Tech Stack and Tools

* Programming Language: Java
* GUI Framework: JavaFX
* Build Tool: Maven
* IDE: IntelliJ IDEA
* Version Control: Git and GitHub

## How to Run

1. Clone the Repository:
   git clone https://github.com/hamnaanoor29/lost-and-found-management-system.git

2. Open in IDE:
   Open IntelliJ IDEA and select Open Folder -> Select lostandfoundsystem.

3. Load Maven Dependencies:
   Wait for Maven to download all required libraries (pom.xml).

4. Run Application:
   Navigate to src/main/java/com/lostandfoundsystem/MainSystem.java and click Run.
